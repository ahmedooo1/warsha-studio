# ورشة العرض

استوديو ثلاثي الأبعاد لنجّاري الموبيليا. يُدخل النجار مقاسات غرفة الزبون، فيرى الزبون مطبخه أو غرفة نومه كما ستكون بعد التنفيذ، بخامات وإضاءة واقعية. ثم يخرج من الأداة عرض سعر جاهز للزبون وورقة تقطيع جاهزة للورشة.

الأداة صفحة واحدة (`index.html`) لا تحتاج خادماً ولا تثبيتاً.

## ما تفعله

**التصميم**
- مطابخ بثلاثة أشكال (مستقيم، زاوية، حرف U) مع جزيرة اختيارية، وغرف نوم بخزانة وسرير وكومودينو.
- مقاسات الجدران والسقف بالسنتيمتر، وتظهر على المشهد مباشرة.
- خامات مرسومة برمجياً: تسعة ألوان وخشبان للواجهات، خمسة أسطح عمل، زليج، أرضيات، مقابض، لمعة أو مطفي.
- إضاءة نهارية ومسائية مع إنارة تحت الخزائن وإنارة معلقة.

**الوحدات**
- تعديل كل جدار وحدةً وحدة من مخطط واجهة مرسوم بالمقاسات، أو بالضغط على الخزانة في المشهد.
- إضافة، حذف، تكرار، تحريك، تغيير العرض والنوع، مع تراجع وتوزيع تلقائي.
- الأنواع: خزانة بباب، جوارير، مجلى، فرن وغاز، جلاية، رفوف مفتوحة، فراغ، عمود ثلاجة، خزانة مؤن، عمود فرن ومايكرويف، خزانة علوية، باب زجاج، باب قلاب، رف مفتوح، شفاط، نافذة. وفي الخزانة: باب تعليق، مرآة، جوارير مع باب، رفوف.
- تنبيه عند زيادة الوحدات عن طول الجدار، وقطعة تعبئة تلقائية للفراغ الصغير.

**الورشة والسعر**
- قائمة تقطيع كاملة بالمليمتر: الجوانب والقواعد والرفوف والظهور والواجهات والوزرات، مع الحواف والسماكة والخامة ورمز كل وحدة.
- حساب الألواح المطلوبة (280×207 مع هدر 15%) وشريط الحواف والإكسسوارات (مفصلات، سكك، مقابض، أرجل، آليات قلاب، قضبان تعليق) والأجهزة المدمجة.
- تكلفة المواد والأجرة والربح التقديري حسب أسعار الورشة.
- **عرض سعر PDF للزبون**: صورة ثلاثية الأبعاد بالمقاسات، المواصفات، جدول السعر مع الضريبة والدفعة الأولى، واجهات الجدران، وخانات التوقيع.
- **ورقة الورشة PDF**: الألواح، سطح العمل، الإكسسوارات، واجهات مرقّمة برموز الوحدات، قائمة التقطيع، والتكلفة والربح.
- **قائمة التقطيع CSV** لبرامج تحسين التقطيع وExcel.

**الزبائن**
- حفظ تصميم كل زبون مع هاتفه وملاحظاته وصورة مصغّرة، وفتحه لاحقاً.
- تصدير صورة للزبون جاهزة لواتساب.

## التشغيل

افتح `index.html` في المتصفح مباشرة، أو شغّل خادماً محلياً:

```bash
npx serve .
```

### النشر على GitHub Pages

من إعدادات المستودع: **Settings ← Pages ← Deploy from a branch**، ثم اختر الفرع `main` والمجلد `/ (root)`. تصبح الأداة متاحة على:

```
https://ahmedooo1.github.io/warsha-studio/
```

## ملاحظات تقنية

- العرض ثلاثي الأبعاد بـ [three.js](https://threejs.org) ‏r147 (نسخة UMD من jsDelivr)، والخامات كلها مولّدة في المتصفح، فلا توجد ملفات صور.
- ملفات PDF تُرسم صفحاتها على canvas بمقاس A4 ودقة 150 نقطة في البوصة، ثم تُجمع في ملف PDF بكاتب صغير داخل الصفحة، فيبقى الخط العربي سليماً دون مكتبات إضافية.
- خارج Claude تُحفظ التصاميم والأسعار في متصفح الجهاز (`localStorage`)، فلا تنتقل بين الأجهزة.
- مساعد «طلب الزبون» الذي يحوّل كلام الزبون إلى تصميم يعمل فقط عند فتح الصفحة كـ Artifact داخل Claude، ويختفي في النسخة المستقلة.

## الخطوات القادمة

- رسم الغرفة بحرية: جدران بأي طول وزاوية، أبواب، أعمدة، تمديدات.
- سحب وإفلات القطع في المشهد، وتعديل العمق والارتفاع.
- قواعد تنبيه: الجلاية بعيدة عن المجلى، الغاز قرب النافذة، تصادم الأبواب، الممرات الضيقة.
- رابط مشاركة للزبون، وعرض بالواقع المعزز.
- نسخة بخادم (Nuxt وNestJS) للحسابات وتوليد صور واقعية بالذكاء الاصطناعي داخل صورة غرفة الزبون.
