# ورشة العرض

استوديو ثلاثي الأبعاد لنجّاري الموبيليا. يُدخل النجار مقاسات غرفة الزبون، فيرى الزبون غرفته كما ستكون بعد التنفيذ، بخامات وإضاءة واقعية. ثم يخرج من الأداة عرض سعر جاهز للزبون وورقة تقطيع جاهزة للورشة.

الأداة صفحة واحدة (`index.html`) لا تحتاج خادماً ولا تثبيتاً.

## الغرف

مطبخ، غرفة نوم، صالون وجدار تلفزيون، غرفة سفرة، غرفة ملابس، غرفة أطفال، مكتب، حمام، مدخل، غرفة غسيل، وغرفة حرة يُركّب فيها أي شيء.

لكل غرفة جدار واحد أو جداران أو ثلاثة، بمقاسات بالسنتيمتر، وتوزيع تلقائي يناسبها، يمكن تعديله بالكامل.

## الوحدات على الجدران

كل جدار له مستويان: على الأرض وعلى الجدار. تُعدّل الوحدات من مخطط واجهة مرسوم بالمقاسات، أو بالضغط عليها في المشهد: إضافة، حذف، تكرار، تحريك، العرض، النوع، وخيارات كل نوع.

| المجموعة | الأنواع |
|---|---|
| المطبخ | خزانة بباب، جوارير (2 أو 3 أو 4)، مجلى، فرن وغاز، جلاية، رفوف مفتوحة، غسالة تحت السطح، عمود ثلاجة (مدمجة أو مستقلة ستيل)، خزانة مؤن، عمود فرن ومايكرويف، خزائن علوية، باب زجاج، باب قلاب، رف مفتوح، شفاط (مدخنة أو صندوق) |
| الخزائن الطويلة | باب تعليق، باب مرآة، جوارير وباب، رفوف مفتوحة، مكتبة رفوف (عدد الرفوف، أبواب سفلية، إضاءة)، فاترينة زجاج بإضاءة، خزانة معاطف، عمود حمام معلّق، عمود غسالة ونشافة |
| الوحدات المنخفضة | وحدة تلفزيون (جوارير أو أبواب قلاب أو مفتوحة، معلّقة، إضاءة سفلية)، بوفيه، خزانة مغسلة (حوض أو حوضان، معلّقة)، جزامة، مقعد بجوارير ووسادة، مكتب |
| الديكور | ديكور جدار التلفزيون (شرائح خشب، ألواح، رخام، حجر) مع شاشة 55 إلى 85 بوصة وإضاءة LED، شاشة، رفوف عائمة، خزانة مرآة، مرآة جدار، لوحات وإطارات صور ومرآة دائرية، علاقة معاطف، نافذة بستائر، باب الغرفة |

## القطع المستقلة

سرير (ثلاثة أشكال للوح الخلفي، جوارير تحت السرير)، سرير بطابقين، كومودينو بأباجورة، تسريحة بمرآة، كومودا جوارير، طاولة سفرة مستطيلة أو بيضاوية مع كراسي، طاولة وسط، كنبة مستقيمة أو زاوية، كرسي استرخاء، كرسي مكتب، سجادة، نبتة، إضاءة أرضية، مرحاض، كابينة دوش، بانيو.

تُسحب القطع في المشهد على الأرض، وتُدوّر 90 درجة، ويُكتب مكانها بالسنتيمتر عند الحاجة.

## الخامات

14 لوناً وخشبان للواجهات، لمعة أو مطفي، لون مختلف للخزائن العلوية، خشب الديكور للرفوف والأسطح والشرائح، 5 أسطح عمل، زليج، 6 أقمشة، 5 مقابض، 4 أرضيات، 6 ألوان جدران. إضاءة نهارية ومسائية مع LED وأباجورات وإنارة معلقة.

## الورشة والسعر

- قائمة تقطيع بالمليمتر لكل الوحدات والقطع المستقلة: الجوانب والقواعد والرفوف والظهور والواجهات والوزرات والأسطح، مع الحواف والسماكة والخامة ورمز كل وحدة.
- الألواح المطلوبة لكل خامة (280×207 مع هدر 15%)، شريط الحواف، الإكسسوارات (مفصلات، سكك، مقابض، أرجل، حوامل تعليق، حوامل رفوف مخفية، مفصلات جزامة، LED، تنجيد…) والأجهزة.
- تسعير البيع حسب الفئة: متر طولي للخزائن السفلية والعلوية والوحدات المنخفضة والمكاتب والرفوف، متر مربع للخزائن الطويلة والديكور والمرايا والأسطح، وبالقطعة للأعمدة والأسرّة والطاولات وغيرها.
- تكلفة المواد والأجرة والربح التقديري حسب أسعار الورشة.
- **عرض سعر PDF للزبون** و**ورقة ورشة PDF** و**قائمة تقطيع CSV**.

## الزبائن

حفظ تصميم كل زبون مع هاتفه وملاحظاته وصورة مصغّرة، وتصدير صورة للزبون جاهزة لواتساب.

## التشغيل

افتح `index.html` في المتصفح مباشرة، أو:

```bash
npx serve .
```

النسخة المنشورة: https://ahmedooo1.github.io/warsha-studio/

## ملاحظات تقنية

- العرض بـ [three.js](https://threejs.org) ‏r147، والخامات مولّدة في المتصفح دون ملفات صور.
- ملفات PDF تُرسم على canvas بمقاس A4 ثم تُجمع بكاتب PDF صغير داخل الصفحة، فيبقى الخط العربي سليماً.
- خارج Claude تُحفظ التصاميم والأسعار في متصفح الجهاز (`localStorage`).
- مساعد «طلب الزبون» يعمل فقط عند فتح الصفحة داخل Claude.
- قائمة التقطيع تقديرية وتفترض هيكلاً من ملامين 18 مم وظهراً من HDF ‏3 مم، فتُراجع مع طريقة تصنيع الورشة.

## الخطوات القادمة

- رسم الغرفة بجدران بأي زاوية وأعمدة وتمديدات.
- قواعد تنبيه للمسافات والتصادم.
- رابط مشاركة للزبون وعرض بالواقع المعزز.
- نسخة بخادم للحسابات وتوليد صور واقعية داخل صورة غرفة الزبون.
