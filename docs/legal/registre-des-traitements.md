# Registre des traitements : fiche « Clients, projets et devis »

> Modèle à faire relire par un avocat ou un juriste. À compléter par l'atelier.

| Rubrique | Contenu |
|---|---|
| Responsable de traitement | [Nom de l'atelier], [adresse], [contact] |
| Sous-traitant | [Nom du prestataire], contrat de sous-traitance du [date] |
| Finalités | Concevoir et présenter des projets d'aménagement ; établir, envoyer et conserver les devis ; suivre leur acceptation ; partager un projet avec le client |
| Base légale | Mesures précontractuelles et exécution du contrat (article 6.1.b) ; obligation légale pour la conservation des pièces comptables (article 6.1.c) |
| Personnes concernées | Clients, prospects ; utilisateurs de l'atelier |
| Catégories de données | Identité et contact (nom, téléphone), plans et dimensions des pièces, notes de l'atelier, devis et montants, nom saisi lors de l'acceptation ; pour les utilisateurs : nom, e-mail, connexions |
| Destinataires | Personnel de l'atelier habilité ; le sous-traitant pour l'hébergement ; le client lui-même par lien |
| Transferts hors UE | Aucun, sauf si l'assistant de conception est activé (voir contrat de sous-traitance, annexe 2) |
| Durées | Prospects 3 ans après le dernier contact ; clients 3 ans après la fin de la relation ; devis 10 ans ; sauvegardes jusqu'à 24 mois |
| Sécurité | Voir l'annexe 1 du contrat de sous-traitance |
| Exercice des droits | Auprès de l'atelier : [adresse e-mail] ; réponse sous un mois ; outil de recherche, d'export et d'effacement dans la gestion de l'atelier |
